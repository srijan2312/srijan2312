### 🔄 SkillSwap — Peer-to-Peer Skill Exchange Platform

A full-stack MERN platform that enables users to exchange skills through peer-to-peer learning.

**Key Features**
- JWT authentication and protected routes
- User profiles
- Discover skills to learn and users looking to learn your skills

- Complete swap lifecycle
- Pending → Accepted/Rejected → Completed states

- Reviews and ratings contributing to user reputation

**Tech:** React.js · Vite · Tailwind CSS · Node.js · Express.js · MongoDB · Mongoose · REST APIs · JWT
